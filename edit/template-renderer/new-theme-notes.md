## Features to build into the new theme
1. Screen-share mode: presenter hidden while a screen recording is shown full frame, or a small
   rounded-rectangle presenter card in a corner. Switches per directive segment.
2. Spotlight box: zoom into the content being spoken about, dim and blur the rest, frame it with a
   rounded accent outline plus glow; optional marker highlight on the key sentence; can pan to a
   second box. The user specifically likes this.
3. Light explainer cards: white rounded cards, thin outlines, grey skeleton placeholder bars,
   brand logo tiles, thin connector lines, soft pastel wash along the top edge.
4. Dark section title cards: charcoal/teal-black ground, diagonal accent lines, plus-sign grid,
   condensed uppercase title with glow, brand tiles joined by plus signs.
5. Split-screen with label tags (CHAT #1 / CHAT #2), glitch fast-forward transition, a glowing
   line sweep that points at an item, word-by-word highlighted captions.
